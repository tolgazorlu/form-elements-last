# Form Elements (Last)

A static demo site with a page per common web form/UI element, built for QA/test-automation practice.

## About
A set of plain HTML pages, each isolating one UI interaction pattern (ajax loading, drag and drop, modals, calendars, file upload, nested sub-pages, etc.), originally built around the Testpine branding as test-automation targets. Built December 2021.

## Features
- Index page linking every element demo
- Ajax content loading
- Autocomplete textbox
- Radio & checkbox inputs
- Drag and drop
- Select list, calendar, modal, alert
- Mouse right-click and simple/load-more scrolling demos
- File upload
- Multi-level nested sub-pages (3-level, 6-level) for crawler/navigation testing
- Broken link and new tab/window demos

## Tech stack
- Static HTML/CSS/JS
- Bootstrap 5 (CDN)
- jQuery (bundled)

## Project structure
```
index.html     # links to every element demo
elements/      # one HTML page per UI element/pattern
assets/, css/, js/, img/   # static assets
```

## Getting started
Open `index.html` in a browser, no build step required.
